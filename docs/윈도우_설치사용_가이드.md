# DesignMap 윈도우(Windows) 설치·사용 가이드

프로그램 본체(Python 코드)는 맥과 윈도우에서 **동일하게** 동작합니다.
윈도우에서는 `.command` 파일 대신 아래 **`.bat` 파일**을 더블클릭하면 됩니다.

| 하고 싶은 일 | 맥(macOS) | 윈도우(Windows) |
|---|---|---|
| 웹 화면 켜기 | `웹화면_실행.command` | **`웹화면_실행.bat`** |
| 최신 코드 받기 | `update.command` | **`업데이트.bat`** |
| AI 열쇠 저장 | 터미널 `export ...` | **`AI열쇠_설정.bat`** |

---

## 처음 한 번만 하는 설치 (약 10~15분)

### 1. Python 설치
1. https://www.python.org/downloads/ 접속 → **Download Python** 노란 버튼 클릭
2. 받은 파일 실행 → 설치 첫 화면에서 **"Add python.exe to PATH" 체크박스를 반드시 켜고** → Install Now
   - ⚠️ 이 체크를 빼먹으면 실행 파일이 python을 못 찾습니다. 빼먹었다면 다시 설치하며 체크하세요.

### 2. Git 설치 (코드 자동 업데이트용)
1. https://git-scm.com/download/win 접속 → 자동으로 다운로드됨
2. 받은 파일 실행 → 설정은 전부 **기본값 그대로 Next** → Install

### 3. 코드 받기 (GitHub Desktop 권장)
1. https://desktop.github.com → 설치 → GitHub 로그인
2. **File → Clone repository** → `koreanha/designmap` 선택 → Clone
3. 상단 **Current Branch** → `claude/design-patent-classifier-6hsbdw` 선택

### 4. 프로그램 설치
클론된 폴더에서 **`업데이트.bat` 더블클릭** (최신 코드 확인 + 필요한 부품 자동 설치)

### 5. AI 열쇠 등록
폴더 안의 **`AI열쇠_설정.bat` 더블클릭** → console.anthropic.com에서 발급받은
열쇠(sk-ant-...)를 붙여넣고 엔터 → 완료.

## 평소 사용법

1. **`웹화면_실행.bat` 더블클릭** → 잠시 후 브라우저에 화면이 열립니다
2. 왼쪽 메뉴에서 ①→⑦ 순서로 진행 (맥과 완전히 동일)
3. 끝나면 검은 창에서 **Ctrl+C** 를 누르거나 창을 닫으면 종료

### 코드 업데이트가 있을 때
1. 웹 화면 검은 창 닫기 (Ctrl+C)
2. **`업데이트.bat` 더블클릭** (또는 GitHub Desktop에서 Pull origin)
3. **`웹화면_실행.bat` 다시 더블클릭**
- 데이터(`data` 폴더)는 업데이트해도 그대로 유지됩니다.

## 자주 나오는 문제

| 증상 | 해결 |
|---|---|
| "python은(는) 내부 또는 외부 명령... 이 아닙니다" | Python 설치 시 "Add to PATH" 체크를 안 한 것 → Python 재설치하며 체크 |
| bat 더블클릭 시 창이 바로 꺼짐 | 폴더에서 주소창에 `cmd` 입력 후 엔터 → `웹화면_실행.bat` 타이핑해 실행하면 오류 메시지를 볼 수 있음 |
| "AI 열쇠 없음 🔴" 표시 | `AI열쇠_설정.bat` 실행 후 **웹 화면을 새로** 켜기 (열려 있던 창은 인식 못 함) |
| 한글 파일명이 깨져 보임 | 압축(ZIP)으로 받았다면 반디집/윈도우 기본 해제 사용. GitHub Desktop 클론이면 발생하지 않음 |
| 폴더 찾아보기 팝업이 안 뜸 | 작업표시줄에 새 창이 깜빡이는지 확인 (뒤에 열림). 안 되면 경로를 직접 입력 |

### 맥에서 쓰던 데이터 옮기기
맥의 코드 폴더 안 **`data` 폴더**를 통째로 복사해 윈도우 코드 폴더 안에 붙여넣으면
디자인권·분류 결과·기준 이력이 그대로 이어집니다.
단, 엑셀 "대표도면 포함"용 **도면 이미지는 PDF 폴더 옆 `drawings` 폴더**에 있으므로,
PDF 폴더도 함께 옮기고 윈도우에서 ① PDF 읽기를 한 번 다시 실행하는 것이 가장 확실합니다
(경로가 맥 형식으로 저장되어 있기 때문).
