# 디자인맵 초보자 실행 가이드 (저장된 공보 PDF 활용)

> 이 문서는 **코딩을 전혀 모르는 분**을 위한 가이드입니다.
> 하드디스크/폴더에 저장해 둔 디자인 공보 PDF 파일을 이용해
> 디자인권을 자동 분류하는 전체 과정을 순서대로 설명합니다.
>
> 컴퓨터에 **명령어를 한 줄씩 복사해서 붙여넣기만** 하면 됩니다.

---

## 들어가기 전에: 꼭 알아야 할 2가지 개념

### 1) "터미널(Terminal)"이란?

우리가 마우스로 클릭하는 대신, **글자로 명령을 내리는 검은 창**입니다.
이 프로그램은 이 창에 명령어를 한 줄씩 입력해서 실행합니다.
무서워 보이지만, **아래 명령어를 그대로 복사 → 붙여넣기 → Enter** 만 하면 됩니다.

### 2) "폴더 경로"란?

내 PDF 파일이 어디에 있는지 알려주는 **주소**입니다.
예를 들어 바탕화면의 `디자인공보` 폴더라면:
- Windows: `C:\Users\내이름\Desktop\디자인공보`
- Mac: `/Users/내이름/Desktop/디자인공보`

이 주소를 나중에 명령어에 넣어줍니다. (구하는 법은 아래 STEP 3에 있습니다)

---

# 1부. 준비 작업 (최초 1회만)

## STEP 1. 파이썬(Python) 설치하기

이 프로그램은 "파이썬"이라는 언어로 만들어져서, 파이썬이 먼저 깔려 있어야 합니다.

### Windows

1. 웹브라우저에서 https://www.python.org/downloads/ 접속
2. 노란색 **"Download Python 3.x.x"** 버튼 클릭
3. 받은 파일을 더블클릭해서 설치 시작
4. ⚠️ **중요**: 설치 첫 화면 맨 아래 **"Add Python to PATH"** 체크박스를 꼭 ✅ 체크하세요!
5. **"Install Now"** 클릭 → 완료될 때까지 기다리기

### Mac

1. 웹브라우저에서 https://www.python.org/downloads/ 접속
2. **"Download Python 3.x.x"** 버튼 클릭
3. 받은 파일(.pkg)을 더블클릭 → "계속" 버튼만 계속 눌러 설치

---

## STEP 2. 터미널 열기

### Windows
1. 키보드에서 **윈도우 키**(⊞) 누르기
2. `cmd` 라고 입력
3. **"명령 프롬프트"** 클릭 → 검은 창이 열립니다

### Mac
1. **Command(⌘) + 스페이스바** 동시에 누르기
2. `터미널` 또는 `terminal` 입력
3. **"터미널"** 클릭 → 흰/검은 창이 열립니다

> 이제부터 "터미널에 입력"이라고 하면 이 창에 글자를 치는 것을 말합니다.

### 파이썬이 잘 깔렸는지 확인

터미널에 아래를 입력하고 Enter:

```
python --version
```

`Python 3.11.x` 처럼 숫자가 나오면 성공입니다.
(Mac에서 안 되면 `python3 --version` 으로 시도해 보세요)

---

## STEP 3. 디자인맵 프로그램 내려받기 & 설치

### 3-1. 프로그램 파일 준비

프로그램 파일(폴더 이름: `designmap`)을 컴퓨터에 받아 둡니다.
- 압축파일(zip)로 받았다면 → 마우스 우클릭 → "압축 풀기"
- 어디에 풀었는지 위치를 기억하세요 (예: 바탕화면)

### 3-2. 터미널을 그 폴더로 이동시키기

터미널에 `cd ` (cd 뒤에 띄어쓰기 한 칸)를 입력한 다음,
**designmap 폴더를 터미널 창 안으로 마우스로 끌어다 놓기(드래그)** 하세요.
그러면 폴더 주소가 자동으로 입력됩니다. 그 상태로 Enter.

예시 (직접 입력해도 됩니다):
```
cd C:\Users\내이름\Desktop\designmap
```
(Mac이면 `cd /Users/내이름/Desktop/designmap`)

### 3-3. 설치 명령 한 줄 실행

터미널에 아래를 그대로 복사 → 붙여넣기 → Enter:

```
pip install -e .
```

(Mac에서 안 되면 `pip3 install -e .`)

여러 줄의 글자가 주르륵 올라가다가 멈추면 설치 완료입니다.
마지막에 `Successfully installed designmap` 같은 글자가 보이면 성공!

---

## STEP 4. AI 열쇠(API 키) 등록하기

이 프로그램은 그림(도면)을 보고 분류할 때 **클로드 AI**를 사용합니다.
AI를 쓰려면 "API 키"라는 비밀번호 같은 열쇠가 필요합니다.

### 4-1. 열쇠 발급받기
1. https://console.anthropic.com 접속 → 회원가입/로그인
2. 왼쪽 메뉴에서 **"API Keys"** 클릭
3. **"Create Key"** 버튼 클릭 → 만들어진 열쇠(`sk-ant-...`로 시작)를 복사
   - ⚠️ 이 열쇠는 한 번만 보여주므로 메모장에 붙여 저장해 두세요

### 4-2. 열쇠를 프로그램에 알려주기

터미널에 아래를 입력하되, `여기에열쇠붙여넣기` 부분을 복사한 열쇠로 바꾸세요.

**Windows:**
```
set ANTHROPIC_API_KEY=여기에열쇠붙여넣기
```

**Mac:**
```
export ANTHROPIC_API_KEY=여기에열쇠붙여넣기
```

> ⚠️ 주의: 이 열쇠 설정은 **터미널 창을 닫으면 사라집니다.**
> 터미널을 새로 열 때마다 이 명령(4-2)을 다시 한 번 입력해야 합니다.

# 2부. 실제 분류 작업 (PDF 공보 활용)

> 준비가 끝났습니다! 이제부터가 실제 작업입니다.
> 앞으로는 **2부만 반복**하면 됩니다. (1부는 처음 한 번만)

## 작업 전체 흐름 한눈에 보기

```
①PDF 읽기 → ②노이즈 제거 → ③기준 제안 → ④내가 검토 → ⑤분류 → ⑥리포트
 parse-pdf    screen        propose      (파일수정)   classify   report
```

---

## STEP 5. ① 저장된 PDF 공보 읽어들이기

내 PDF 공보 파일들이 들어있는 폴더를 프로그램에게 읽게 합니다.

### 5-1. PDF 폴더 정리
나라별로 폴더를 나눠 두는 것이 좋습니다. 예:
```
디자인공보/
├── 한국/   (한국 공보 PDF들)
├── 미국/   (미국 공보 PDF들)
└── 일본/   (일본 공보 PDF들)
```

### 5-2. 읽기 명령 실행

아래 명령에서 `폴더경로` 부분에 **PDF가 든 폴더를 드래그**해서 주소를 넣고,
`--office` 뒤에는 나라 코드를 적습니다.

**한국 공보 예시:**
```
designmap parse-pdf 폴더경로 --office KIPO
```

실제로는 이렇게 됩니다 (폴더를 드래그하면 주소가 자동 입력됨):
```
designmap parse-pdf C:\Users\내이름\Desktop\디자인공보\한국 --office KIPO
```

**나라별 코드:**
| 나라 | 코드 | 명령 예시 |
|------|------|-----------|
| 한국 | KIPO | `designmap parse-pdf [폴더] --office KIPO` |
| 미국 | USPTO | `designmap parse-pdf [폴더] --office USPTO` |
| 유럽 | EUIPO | `designmap parse-pdf [폴더] --office EUIPO` |
| 중국 | CNIPA | `designmap parse-pdf [폴더] --office CNIPA` |
| 일본 | JPO | `designmap parse-pdf [폴더] --office JPO` |

> 나라별 폴더가 여러 개면, 위 명령을 나라마다 한 번씩 실행하면 됩니다.

실행하면 PDF에서 **출원번호, 물품명, 출원인, 분류, 도면**을 자동으로 뽑아내어
`data` 폴더 안에 `parsed_patents.xlsx`(엑셀 파일)로 저장합니다.
이 엑셀을 열어보면 추출된 내용을 눈으로 확인할 수 있습니다.

---

## STEP 6. ② 1차 스크리닝 (관계없는 것 걸러내기)

분석하려는 분야와 관계없는 디자인을 자동으로 걸러냅니다.

```
designmap screen --locarno 14-03 --keywords "스마트폰,휴대폰" --exclude "케이블,충전기"
```

- `--locarno 14-03` : 분석할 로카르노 분류 번호 (예: 14-03은 통신기기)
- `--keywords` : 포함하고 싶은 단어들 (쉼표로 구분)
- `--exclude` : 빼고 싶은 단어들 (쉼표로 구분)

실행하면 "통과 / 제외" 건수가 표로 나옵니다.

---

## STEP 7. ③ AI가 분류 기준 제안하기

AI가 도면들을 보고 "이런 기준으로 나누면 좋겠다"고 제안합니다.

```
designmap propose --locarno 14-03 --context "스마트폰 외관 디자인 트렌드 분석"
```

- `--context` 뒤에는 내가 분석하려는 목적을 자유롭게 적으면 됩니다.

실행하면 제안 내용이 화면에 나오고, `data/proposed_criteria.json` 파일로 저장됩니다.

---

## STEP 8. ④ 제안된 기준을 내가 검토/수정하기 (가장 중요!)

이 단계가 "AI 제안 → 사람이 확정"하는 핵심 단계입니다.

1. `designmap` 폴더 안의 `data` 폴더를 엽니다
2. `proposed_criteria.json` 파일을 **메모장**(Mac은 "텍스트 편집기")으로 엽니다
3. 내용을 읽어보고 분류 기준을 원하는 대로 고칩니다
   (마음에 들면 안 고쳐도 됩니다)
4. 파일 안에서 아래 글자를 찾습니다:
   ```
   "status": "proposed"
   ```
   이것을 아래처럼 바꿉니다:
   ```
   "status": "approved"
   ```
   ("proposed"→"approved", 제안됨→승인됨 으로 바꾸는 것)
5. 저장(Ctrl+S, Mac은 ⌘+S)하고 닫습니다

> 💡 `proposed`(제안됨) 상태에서는 다음 단계가 "정말 진행할까요?"라고 물어봅니다.
> `approved`(승인됨)로 바꿔두면 바로 진행됩니다.

---

## STEP 9. ⑤ 실제 분류 실행

내가 확정한 기준으로 모든 디자인권을 분류합니다.

```
designmap classify
```

실행하면 카테고리별 건수가 표로 나오고,
결과가 `data/classification_results.json` 에 저장됩니다.

---

## STEP 10. ⑥ 트렌드 예측 리포트 받기

분류 결과를 종합해 미래 디자인 트렌드 리포트를 만듭니다.

```
designmap report --context "2025년 이후 스마트폰 디자인 방향 예측"
```

완성된 리포트는 `data/trend_report.md` 파일로 저장됩니다.
이 파일을 메모장으로 열면 분석 리포트를 읽을 수 있습니다.

# 자주 묻는 질문 (문제 해결)

**Q. `designmap` 을 입력했더니 "명령을 찾을 수 없습니다"라고 나와요.**
→ STEP 3-3 설치(`pip install -e .`)가 안 된 것입니다. 다시 해보세요.
→ 또는 터미널이 `designmap` 폴더 안에 있는지 확인하세요 (STEP 3-2).

**Q. "ANTHROPIC_API_KEY" 관련 오류가 나요.**
→ STEP 4-2를 다시 실행하세요. 터미널을 새로 열면 매번 다시 해야 합니다.

**Q. PDF를 읽었는데 내용이 비어있거나 이상해요.**
→ 스캔된(사진처럼 된) PDF일 수 있습니다. 이 경우 AI(API 키)가 자동으로 글자를
   읽어내므로, STEP 4의 API 키가 등록돼 있어야 합니다.

**Q. `python` 이 안 되고 `python3` 은 돼요. (주로 Mac)**
→ 모든 명령에서 `python`을 `python3`, `pip`을 `pip3`으로 바꿔 쓰면 됩니다.

**Q. 한글이 깨져 보여요. (주로 Windows)**
→ 터미널에 `chcp 65001` 을 한 번 입력하고 Enter 친 뒤 작업하면 한글이 잘 나옵니다.
