# 맥북(Mac) 설치 & 사용 가이드 — PDF 디자인공보 활용

> 맥북을 쓰고, 디자인공보를 **PDF 원본 파일**로 가지고 있는 분을 위한 가이드입니다.
> 코딩을 몰라도 됩니다. **명령어를 복사 → 터미널에 붙여넣기 → Enter** 만 반복하면 됩니다.
>
> 복사/붙여넣기: 명령어를 드래그해 복사(⌘C), 터미널에서 붙여넣기(⌘V).

---

# 1부. 준비 작업 (처음 딱 한 번만)

## STEP 1. 터미널 열기

1. 키보드에서 **⌘(커맨드) + 스페이스바** 동시에 누르기
2. `터미널` 이라고 입력
3. 나오는 **"터미널"** 앱을 클릭 → 흰색(또는 검은색) 창이 열립니다

> 앞으로 "터미널에 입력"은 이 창에 붙여넣고 Enter 치는 것을 말합니다.

---

## STEP 2. 파이썬(Python) 설치

이 프로그램은 "파이썬" 언어로 만들어져, 파이썬이 먼저 필요합니다.
맥에 기본 파이썬이 있긴 하지만, 문제가 적도록 **새로 설치**하는 것을 권장합니다.

1. 사파리/크롬에서 https://www.python.org/downloads/ 접속
2. 큰 노란 버튼 **"Download Python 3.x.x"** 클릭
3. 다운로드된 `.pkg` 파일을 더블클릭
4. "계속 → 계속 → 동의 → 설치" 순서로 클릭 (비밀번호 물어보면 맥 로그인 암호 입력)

설치 후, 터미널에 아래를 입력해 확인:

```
python3 --version
```

`Python 3.11.x` 처럼 숫자가 나오면 성공입니다.

> 💡 맥에서는 `python` 이 아니라 **`python3`**, `pip` 대신 **`pip3`** 을 씁니다.
> 이 가이드의 명령어는 이미 그렇게 맞춰져 있습니다.

---

## STEP 3. 디자인맵 프로그램 내려받기

프로그램 코드는 GitHub(깃허브)라는 곳에 저장돼 있습니다. ZIP 파일로 받겠습니다.

### 방법 A — 웹에서 ZIP 다운로드 (가장 쉬움)

1. 브라우저에서 프로그램 GitHub 페이지로 이동
   (브랜치: `claude/design-patent-classifier-6hsbdw`)
2. 초록색 **"Code"** 버튼 클릭 → **"Download ZIP"** 클릭
3. 다운로드 폴더에 받아진 ZIP 파일을 **더블클릭** → 압축이 풀립니다
4. 풀린 폴더(`designmap-...`)를 **바탕화면**으로 옮겨두면 찾기 쉽습니다

### 방법 B — git 명령으로 받기 (git이 깔려 있다면)

```
cd ~/Desktop
git clone <프로그램_주소> designmap
cd designmap
git checkout claude/design-patent-classifier-6hsbdw
```

---

## STEP 4. 터미널을 프로그램 폴더로 이동

1. 터미널에 `cd ` 를 입력합니다 (cd 뒤에 **띄어쓰기 한 칸**)
2. STEP 3에서 풀어둔 **designmap 폴더를 터미널 창 안으로 마우스로 끌어다 놓기**
   → 폴더 주소가 자동으로 채워집니다
3. Enter

이렇게 보이면 됩니다 (예시):
```
cd /Users/내이름/Desktop/designmap
```

> 제대로 들어왔는지 확인하려면 `ls` 입력 후 Enter.
> `pyproject.toml`, `src`, `README.md` 같은 이름이 보이면 맞게 들어온 것입니다.

---

## STEP 5. 프로그램 설치

터미널에 아래를 붙여넣고 Enter:

```
pip3 install -e .
```

글자가 주르륵 올라가다 멈추고, 마지막에
`Successfully installed designmap` 비슷한 문구가 나오면 성공입니다.

> ⚠️ 만약 `pip3: command not found` 가 나오면 STEP 2(파이썬 설치)를 다시 확인하세요.

설치 확인:
```
designmap --help
```
명령어 목록(template, parse-pdf, screen ...)이 표로 나오면 완벽합니다.

---

## STEP 6. AI 열쇠(API 키) 등록 — 한 번만 영구 설정

도면 그림을 보고 분류할 때 **클로드 AI**를 씁니다. 이를 위한 "열쇠"가 필요합니다.

### 6-1. 열쇠 발급
1. https://console.anthropic.com 접속 → 가입/로그인
2. 왼쪽 **"API Keys"** → **"Create Key"** 클릭
3. 생성된 열쇠(`sk-ant-...`로 시작)를 복사 (메모장에도 저장해두기)

### 6-2. 열쇠를 맥에 영구 저장하기

아래 명령에서 `여기에열쇠붙여넣기` 를 복사한 열쇠로 바꿔서 터미널에 입력:

```
echo 'export ANTHROPIC_API_KEY=여기에열쇠붙여넣기' >> ~/.zshrc
```

그다음, 설정을 적용하려면:
```
source ~/.zshrc
```

> 이렇게 하면 터미널을 새로 열어도 열쇠가 계속 기억됩니다. (한 번만 하면 됨)
> 잘 됐는지 확인: `echo $ANTHROPIC_API_KEY` → 열쇠가 보이면 성공.

# 2부. 실제 분류 작업 (앞으로 이 부분만 반복)

> 전체 흐름:
> ```
> ① PDF 읽기 → ② 거르기 → ③ 기준 제안 → ④ 내가 검토 → ⑤ 분류 → ⑥ 리포트
> ```

매번 시작할 때, 터미널을 열고 **폴더로 이동**만 하면 됩니다 (열쇠는 이미 영구 저장됨):
```
cd ~/Desktop/designmap
```

---

## STEP 7. ① 저장한 PDF 공보 읽어들이기

### 7-1. PDF 폴더 준비
내 PDF들을 나라별 폴더로 모아두면 좋습니다. 예:
```
디자인공보/
├── 한국/
├── 미국/
└── 일본/
```

### 7-2. 읽기 명령

아래에서 `[PDF폴더]` 자리에 **PDF가 든 폴더를 터미널로 드래그**해 주소를 넣으세요.

**한국 공보:**
```
designmap parse-pdf [PDF폴더] --office KIPO
```

완성된 예시:
```
designmap parse-pdf /Users/내이름/Desktop/디자인공보/한국 --office KIPO
```

**나라별 코드:**
| 나라 | `--office` 코드 |
|------|------|
| 한국 | KIPO |
| 미국 | USPTO |
| 유럽 | EUIPO |
| 중국 | CNIPA |
| 일본 | JPO |

> 나라 폴더가 여러 개면 나라마다 한 번씩 실행하세요.

실행하면 PDF에서 **출원번호·물품명·출원인·분류·도면**을 자동으로 추출해
`data/parsed_patents.xlsx` 엑셀 파일로 저장합니다. (열어서 눈으로 확인 가능)

> 💡 스캔된(사진 같은) PDF는 글자 추출이 안 되는데, 이때는 AI가 그림을 읽어
> 자동으로 내용을 뽑아냅니다(STEP 6 열쇠 필요). 시간이 조금 더 걸릴 수 있습니다.

---

## STEP 8. ② 1차 스크리닝 (관계없는 디자인 거르기)

```
designmap screen --locarno 14-03 --keywords "스마트폰,휴대폰" --exclude "케이블,충전기"
```

- `--locarno 14-03` : 분석할 로카르노 분류 번호
- `--keywords "..."` : 포함할 단어 (쉼표로 구분)
- `--exclude "..."` : 제외할 단어 (쉼표로 구분)

"통과 / 제외" 건수가 표로 나옵니다.

---

## STEP 9. ③ AI가 분류 기준 제안

```
designmap propose --locarno 14-03 --context "스마트폰 외관 디자인 트렌드 분석"
```

- `--context "..."` : 내 분석 목적을 자유롭게 적기

제안 내용이 화면에 나오고 `data/proposed_criteria.json` 파일로 저장됩니다.

---

## STEP 10. ④ 제안 기준을 내가 검토/확정 (가장 중요)

1. **Finder(파인더)**에서 `designmap` 폴더 → `data` 폴더 열기
2. `proposed_criteria.json` 파일을 우클릭 → "다음으로 열기" → **텍스트 편집기**
3. 분류 기준을 읽고 원하는 대로 수정 (그대로 둬도 됨)
4. 파일에서 이 부분을 찾아:
   ```
   "status": "proposed"
   ```
   이렇게 바꿉니다:
   ```
   "status": "approved"
   ```
5. **⌘ + S** 로 저장

> "proposed(제안됨)" → "approved(승인됨)" 으로 바꾸는 것이 핵심입니다.

---

## STEP 11. ⑤ 분류 실행

```
designmap classify
```

카테고리별 건수가 표로 나오고, 결과가 `data/classification_results.json` 에 저장됩니다.

---

## STEP 12. ⑥ 트렌드 리포트 생성

```
designmap report --context "2025년 이후 스마트폰 디자인 방향 예측"
```

완성된 리포트는 `data/trend_report.md` 에 저장됩니다.
Finder에서 이 파일을 텍스트 편집기로 열면 읽을 수 있습니다.

# 문제가 생기면 (맥 기준 FAQ)

**`designmap: command not found`**
→ STEP 5 설치가 안 됐거나 폴더 밖입니다. `cd ~/Desktop/designmap` 후 `pip3 install -e .` 다시.

**`pip3: command not found`**
→ 파이썬(STEP 2)이 설치 안 됨. python.org에서 다시 설치.

**API 키 관련 오류**
→ `echo $ANTHROPIC_API_KEY` 로 확인. 비어 있으면 STEP 6-2 다시 실행 후 `source ~/.zshrc`.

**"열 수 없음 / 확인되지 않은 개발자" 경고가 떠요**
→ 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "확인 없이 열기" 클릭.

**한글이 깨져 보여요**
→ 터미널 상단 메뉴: 터미널 → 환경설정 → 인코딩이 "유니코드(UTF-8)"인지 확인.
