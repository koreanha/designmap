# 코드 자동 업데이트 가이드 (ZIP 재다운로드 끝내기)

> 매번 ZIP을 새로 받으면 데이터까지 새로 시작해야 합니다.
> **git으로 한 번만 연결**하면, 이후엔 **데이터(DB·PDF·분류기준)는 그대로 둔 채 코드만** 업데이트됩니다.

핵심: 데이터가 들어있는 `data/` 폴더는 git 추적 대상이 아니라서, 코드를 업데이트해도 **사라지지 않습니다.**

---

## 방법 A (추천, 비전공자용): GitHub Desktop 앱

마우스 클릭만으로 코드를 받고 업데이트할 수 있습니다. 터미널로 비밀번호/토큰을 칠 필요가 없습니다.

### 최초 1회 설정
1. https://desktop.github.com 접속 → **Download for macOS** → 설치
2. 앱 실행 → **Sign in to GitHub.com** → 브라우저로 로그인 (ZIP 받던 그 계정)
3. 상단 메뉴 **File → Clone repository**
4. 목록에서 `koreanha/designmap` 선택 (안 보이면 검색창에 입력)
5. **Local path**(저장 위치)를 **홈 폴더**처럼 바탕화면이 아닌 곳으로 지정 → **Clone**
6. 화면 위쪽 **Current Branch** 클릭 → `claude/design-patent-classifier-6hsbdw` 선택

### 설치 (최초 1회)
터미널에서 클론된 폴더로 이동 후:
```
pip3 install -e .
```

### 앞으로 업데이트할 때 (클릭 한 번)
- GitHub Desktop 상단의 **Fetch origin** 클릭 → **Pull origin** 이 뜨면 클릭
- 끝. 데이터는 그대로, 코드만 최신이 됩니다.
- (가끔 새 부품이 필요할 때만 `pip3 install -e .` 한 번 더 — 안내드릴게요)

---

## 방법 B: 터미널 + git (조금 더 직접적)

### 최초 1회
```
# git이 없으면 첫 실행 시 설치 안내창이 뜹니다 → '설치' 클릭
cd ~
git clone https://github.com/koreanha/designmap.git
cd designmap
git checkout claude/design-patent-classifier-6hsbdw
pip3 install -e .
```
> 비공개 저장소라 아이디/토큰을 물어보면, 방법 A(GitHub Desktop)가 훨씬 쉽습니다.

### 앞으로 업데이트할 때
```
cd ~/designmap
git pull
```

또는, 더 간단하게 폴더 안의 **`update.command` 파일을 더블클릭**하면 자동으로 `git pull` + 설치까지 됩니다.

## 자주 묻는 질문

**Q. 업데이트하면 그동안 모은 데이터가 날아가나요?**
→ 아니요. `data/` 폴더(DB, parsed_patents.xlsx, proposed_criteria.json 등)는 git이 건드리지 않습니다.

**Q. PDF 원본도 영향받나요?**
→ 전혀요. PDF는 코드와 별개 위치에 두고 경로로만 가리키므로 안전합니다.

**Q. ZIP으로 받은 기존 폴더는요?**
→ git으로 새로 클론한 뒤에는 기존 ZIP 폴더는 지워도 됩니다. 단, 기존 폴더의 `data/`에
   작업물이 있다면 새 폴더의 `data/`로 복사해 옮기세요.
